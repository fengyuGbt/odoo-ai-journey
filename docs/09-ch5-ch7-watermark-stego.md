# Ch5 模型水印 · Ch7 隐写术 · 在 Odoo 中的落地

> 课程来源：《动手学大模型》Chapter 5 / Chapter 7
> Odoo 关联：内容溯源与合规（B2B 场景价值有限）
> 优先级：★★ 扩展认知

## Ch5 模型水印（Watermark）

### 这一章在讲什么
- **KGW 水印**：在生成文本中嵌入隐形统计标记，可通过算法检测"这段文字是不是 AI 写的"
- **水印 vs 隐写**：水印 = 标记 AI 来源；隐写 = 隐藏任意信息

### Odoo 里的落地（有限）
| 需求 | 做法 |
|---|---|
| AI 生成内容可审计 | 自动生成的内容记来源标记（如 `ai_generated=True` + 生成模型/版本） |
| 内容合规溯源（出海） | 客户问"这封邮件是不是自动发的"时能回答 + 留痕 |
| 真正的模型水印 | 属于模型层，云 API 厂商提供与否你控制不了——知道即可 |

> 工程建议：Odoo 里做"AI 生成留痕"（元数据字段）就够，水印算法本身不用碰。

## Ch7 隐写术（Steganography）

### 这一章在讲什么
- 把任意信息（二进制/文本）藏进模型生成的自然文本，人眼看不出
- 课程用 GPT-2 做演示

### Odoo 里的落地
- **几乎没有直接业务场景**。B2B ERP 不需要"把秘密藏进文本"
- 了解价值：扩展对 LLM 能力的认知（模型能做的事超出直觉）

## 小结

这两章对 Odoo 集成开发是"认知扩展"而非"生产工具"。记住两个概念：
**内容溯源（水印）** 和 **信息隐藏（隐写）**，需要时知道去哪查。
